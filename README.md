## Project Title

## Tasks Completed

### Task 1 – Mobile App Wireframe
Designed low-fidelity wireframes for a Food Delivery mobile application, including key screens and user flow.

### Task 2 – Food Delivery Landing Page
Designed a landing page UI for a food delivery service with navigation, popular dishes, features, and contact information.

### Task 3 – User Persona & Journey Map
Created a user persona and mapped the complete user journey from discovery to order delivery, including goals, behaviors, pain points, and user experience.
